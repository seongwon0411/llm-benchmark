## 개정 SOP: 변경 관리 절차

### 1. 일반 변경 절차
1. **요청 접수**
   - 작업자 차트에 변경 티켓 생성 (예: CHG-20231001)
   - 요청 사유, 영향 범위, 예상 시간 기재
2. **승인 처리**
   - 팀장이 요청자와 승인자를 분리하여 승인 (서명/전자결제)
   - 승인 시점 백업 수행 및 복구 테스트 완료 확인
3. **변경 실행**
   - 변경 이력 로그에 기록 (요청자, 승인자, 변경 내용, 시간)
   - 실시간 모니터링으로 이상 신호 시 즉시 롤백
4. **검증 및 완료**
   - 변경 후 2시간 내 정상 운영 확인
   - 티켓 상태 '완료'로 전환

### 2. 긴급 변경 절차 (24시간 이내 사후 승인)
1. **긴급 조치**
   - 비상 프로토콜에 따라 즉시 실행 (변경자와 보고서 작성자 분리)
   - '긴급' 태그 부여 및 5분 내 팀장에게 알림
2. **사후 승인**
   - 24시간 이내 서면 승인 필수 (미승인 시 롤백)
   - 사전 백업 확인 증빙 자료 보관

### 3. 체크리스트
| 항목 | 확인 여부 |
|------|----------|
| 티켓 생성 및 기록 | ☐ |
| 승인자/요청자 분리 | ☐ |
| 백업 및 복구 테스트 | ☐ |
| 롤백 기준 명확화 | ☐ |
| 긴급 변경 사후 승인 | ☐ |

### 4. 책임자
- **요청자**: 변경 필요성 판단, 이력 기록
- **승인자**: 리스크 검토, 승인 결정
- **운영자**: 실행 및 모니터링
- **보증자**: 사후 검증, 롤백 수행

> *비고: 모든 변경은 시스템 로그와 문서로 기록하여 감사 조사 대비 필요*
