# 장애 사후보고서

## 요약
캐시 키 생성 함수 교체로 인해 배포 중 API 오류율이 급증하여 알람이 발생하였습니다. 이에 따라 빠른 대응으로 롤백 절차가 실행되어 문제를 해결하였습니다.

## 영향
- API 오류율이 2%에서 18%로 급증함
- 약간의 서비스 지연 발생
- 빠른 롤백으로 최소한의 고객 영향 유지

## 타임라인
- **09:02** 배포 시작
- **09:11** API 오류율 2% -> 18%
- **09:14** 알람 발생
- **09:18** 롤백 결정
- **09:24** 롤백 완료
- **09:31** 오류율 1.8%로 회복

## 직접 원인
- 캐시 키 생성 함수 교체로 인한 불일치

## 근본원인/미확정 사항
- 운영 환경과 개발 환경 간의 차이점으로 인해 문제 발생 가능성
- 특정 키 분포에 대한 부하테스트 미실행

## 재발방지 조치
1. 운영 환경과 개발 환경의 차이점을 철저히 검증
2. 특정 키 분포에 대한 부하테스트를 포함하여 전체적인 테스트 수행
3. 롤백 절차 문서화 및 정기적인 리뷰 강화
4. 변경 사항의 영향을 평가하기 위한 추가 검증 단계 도입
