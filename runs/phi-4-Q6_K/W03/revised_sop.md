# 개정된 변경 절차 (SOP)

## 목적
변경 요청의 효율성과 안전성을 높이기 위한 개정된 SOP입니다. 이 문서는 현장 작업자가 바로 쓸 수 있는 단계별 체크리스트를 제공합니다.

## 일반 변경 절차
1. **티켓 번호 생성**
   - 모든 변경 요청은 고유한 티켓 번호가 필요합니다.

2. **변경 요청 작성 및 제출**
   - 작업자는 변경 내용을 문서화하고, 승인자에게 전달합니다.

3. **승인 확인**
   - 승인자는 변경 요청을 검토하여 승인합니다.

4. **백업 및 테스트**
   - 실행 전 필수적으로 백업을 생성하고, 복구 테스트를 수행합니다.

5. **변경 적용**
   - 승인된 변경 사항을 운영 설비에 반영합니다.

6. **모니터링 및 문제 해결**
   - 변경 후 시스템을 모니터링하고, 필요시 롤백합니다.

7. **문서화**
   - 변경 사항과 결과를 기록하여 관리합니다.

## 긴급 변경 절차
1. **긴급 티켓 생성 및 제출**
   - 긴급 변경은 우선적으로 처리되지만, 24시간 이내에 사후승인이 필요합니다.

2. **백업 및 테스트 (가능한 경우)**
   - 시간 여유가 있을 때는 백업과 복구 테스트를 수행합니다.

3. **변경 적용**
   - 긴급 상황에서 필요한 변경 사항을 즉시 반영합니다.

4. **모니터링 및 문제 해결**
   - 변경 후 시스템을 모니터링하고, 필요시 롤백합니다.

5. **사후승인**
   - 24시간 이내에 승인자의 사후승인을 받습니다.

6. **문서화**
   - 긴급 변경 사항과 결과를 기록하여 관리합니다.

## 체크리스트
- [ ] 티켓 번호 생성
- [ ] 변경 요청 작성 및 제출
- [ ] 승인 확인
- [ ] 백업 및 테스트 수행
- [ ] 변경 적용
- [ ] 모니터링 및 문제 해결
- [ ] 사후승인 (긴급 변경 시)
- [ ] 문서화

이 SOP는 작업자가 체크리스트로 사용할 수 있도록 설계되었습니다. 각 단계를 철저히 따르면 안전하고 효율적인 변경을 보장합니다.
