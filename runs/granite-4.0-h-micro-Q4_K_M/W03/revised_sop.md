# Revised Standard Operating Procedure (SOP)
## Check List for Workforce Use
1. **Change Request Submission**
   - Ticket number required ✅
   - Separate requester & approver ✅
2. **Approval Workflow**
   - Non‑urgent changes: Reviewer sign-off only ✅
   - Urgent changes: Immediate action with 24‑hour post‑approval review ✅
3. **Implementation Steps**
   a) Backup current system before any change ✅
   b) Apply approved modifications to operational equipment ✅
   c) Verify rollback criteria are met ✅
4. **Post‑Change Verification**
   - Confirm no new audit findings appear ✅
   - Ensure KPI metrics remain within thresholds ✅
5. **Documentation & Reporting**
   - Record change ticket, approver name, timestamp in `audit_findings.txt` ✅
   - Update `policy.txt` if any procedural gaps are identified ✅
## Key Differences Between Standard and Urgent Changes
- **Standard**: Backup + implementation + verification only ✅
- **Urgent**: Immediate action with 24‑hour post‑approval review, additional risk assessment ✅
