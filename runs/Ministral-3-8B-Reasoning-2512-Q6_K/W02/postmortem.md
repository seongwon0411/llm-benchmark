## 직접 원인 (Root Cause)
- **변경 사항**: 캐시 키 생성 함수를 교체함.
- **문제**: 사전 부하테스트는 개발 환경에서만 수행되어 운영 트래픽과 동일한 키 분포 테스트가 미수행됨. 이는 캐시 키 분포의 불일치로 인해 API 오류율이 급격히 증가한 원인임.

---

## 근본원인/미확정 사항 (Root Cause / Unknowns)
- **근본원인**:
  - 운영 환경과 개발 환경의 캐시 키 분포가 일치하지 않음.
  - 사전 테스트에서 운영 트래픽을 모방할 수 있는 테스트가 부족함.
- **미확정 사항**: 캐시 키 생성 함수의 변경이 오류율 증가에 직접적인 영향을 주었는지 확인하기 위해 추가 분석이 필요함.

---

## 재발 방지 조치 (Preventive Actions)
1. **운영 환경과 일치하는 부하테스트**
   - 운영 트래픽을 모방한 캐시 키 분포 테스트를 수행하여 오류율을 검증.
2. **변경 관리 프로세스 강화**
   - 배포 전 운영 환경과 동일한 조건에서 테스트를 mandatory로 설정.
3. **알람 개선**
   - API 오류율의 급격한 증가에 대한 알람을 더 sensitively 설정.
4. **롤백 절차 문서화**
   - 롤백 절차가 잘 문서화되어 있고, 실제 수행 시간도 6분 내 완료됨.

---

## 다음 단계 (Next Steps)
- 추가 분석: 캐시 키 생성 함수의 변경이 오류율 증가에 직접적인 영향을 주었는지 확인.
- 테스트 프로세스 개선: 운영 환경과 일치하는 부하테스트를 mandatory로 설정.
