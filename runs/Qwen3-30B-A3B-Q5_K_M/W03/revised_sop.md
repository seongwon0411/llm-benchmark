# 개정된 운영 절차(SOP)

## 목적
작업자와 승인자의 역할 분리, 변경 기록 관리, 백업/롤백 기준 명확화를 통해 시스템 안정성 확보

## 체크리스트
1. [ ] 모든 변경에 티켓 번호 입력 (요청서 참조)
2. [ ] 작업자 vs 승인자 분리 (감사 지적 2번 반영)
3. [ ] 실행 전 백업 및 복구 테스트 확인 (정책 요구사항 3번)
4. [ ] 실패 시 롤백 기준 충족 여부 점검 (정책 요구사항 4번)

## 일반 변경 절차
1. 작업자 → 팀장에게 요청서 작성 (티켓 번호 포함)
2. 팀장 승인 후 운영 설비 반영
3. 변경 완료 후 [ ] 백업 파일 확인
4. [ ] 롤백 기준 충족 여부 확인

## 긴급 변경 절차
1. 작업자 → 즉시 조치 가능 (정책 요구사항 5번)
2. [ ] 24시간 이내 사후 승인 완료 필요
3. 긴급 변경 시 [ ] 백업 파일 생성 및 복구 테스트 수행

## 문서화 의무
- 모든 변경 기록은 요청서에 남김 (감사 지적 1번 해소)
- 롤백 책임자는 변경 승인자로 명시 (감사 지적 4번 반영)
