# 사후 분석 보고서

## 요약
배포 중 발생한 API 오류율 증가로 인해 롤백 결정 및 실행이 이루어졌습니다.

## 영향
API 오류율이 2%에서 최대 18%까지 상승했으나, 롤백 후 1.8%로 회복되었습니다.

## 타임라인
- **09:02** 배포 시작
- **09:11** API 오류율이 2%에서 18%로 증가
- **09:14** 알람 발생
- **09:18** 롤백 결정
- **09:24** 롤백 완료
- **09:31** 오류율이 1.8%로 회복

## 직접 원인
캐시 키 생성 함수 교체 후 API 오류율 증가.

## 근본원인/미확정 사항
변경사항에 대한 전면적인 부하테스트를 수행하지 않았음 (운영 트래픽과 동일한 키 분포 테스트 미실시)

## 재발방지 조치
- 모든 배포 이전에 운영 환경과 유사한 키 분포로 부하테스트를 수행
- 변경사항에 대한 롤백 절차의 효율성을 개선
