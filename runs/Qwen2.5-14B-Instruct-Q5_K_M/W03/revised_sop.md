# 개정된 SOP
## 일반 변경 절차
1. 작업자가 변경 요청을 티켓으로 생성하고, 해당 티켓 번호를 기록한다.
2. 팀장이 승인 후, 작업자는 티켓에 승인 확인 메모를 추가한다.
3. 변경 전 백업을 수행하고, 복구 테스트를 진행하며 결과를 티켓에 첨부한다.
4. 변경을 실행한 후, 문제가 발생하면 즉시 롤백 절차를 따르고 롤백이 완료되면 티켓에 기록한다.

## 긴급 변경 절차
1. 작업자가 변경 요청을 티켓으로 생성하고, 해당 티켓 번호를 기록한다.
2. 팀장이 승인 후, 작업자는 티켓에 승인 확인 메모를 추가한다.
3. 변경 전 백업을 수행하며 결과를 티켓에 첨부한다.
4. 변경을 즉시 실행하고, 문제가 발생하면 롤백 절차를 따르고 롤백이 완료되면 티켓에 기록한다.
5. 긴급변경은 24시간 내에 사후 승인을 받아야 한다.

## 체크리스트
- 변경 요청 시 티켓 번호 생성 및 기록
- 승인자와 작업자가 분리되어 있어야 함
- 변경 전 백업 수행 및 복구 테스트 확인
- 롬백 절차 명확히 정의됨
- 긴급변경은 24시간 내 사후승인 필요
