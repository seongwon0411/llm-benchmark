# **사후 조사 보고서**

## **요약**
API 배포 중 캐시 키 생성 함수 교체로 18% 오류율 발생 → 롤백 후 6분 내 복구.

## **영향**
- 운영 중단: API 사용자 5,000명 이상 영향을 받았음.
- 추가 비용: 재발방지 조치로 없음 (사전 테스트 미완료).

## **타임라인**
```plaintext
09:02 - 배포 시작
09:11 - 오류율 2% → 18%
09:14 - 알람 발생
09:18 - 롤백 결정
09:24 - 롤백 완료
09:31 - 회복 (1.8%)
```

## **직접 원인**
- 캐시 키 생성 함수 교체.
- 사전 테스트: 운영 트래픽 시나리오 미반영.

## **근본원인/미확정 사항**
1. 부하테스트 미완료 → 운영 환경과 다름.
2. 롤백 절차 문서화 완료但 수행 시간 6분 초과 가능성 확인 필요.

## **재발방지 조치**
- **기능 테스트**: 운영 트래픽 시나리오 포함 부하테스트 추가.
- **문서화**: 롤백 절차에 최대 수행 시간 10분 이상 가능 여부 명시.
- **자동 모니터링**: 오류율 5% 초과 시 자동 알람 발생.
