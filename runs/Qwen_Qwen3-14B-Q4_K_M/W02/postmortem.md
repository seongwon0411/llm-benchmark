## 요약
캐시 키 생성 함수 교체 배포로 인해 09:11부터 API 오류율이 2% → 18%로 급증한 장애 발생. 6분 내 롤백 완료 후 09:31에 정상 회복.

## 영향
- 서비스 중단 시간: 약 30분 (09:11~09:41)
- 오류율 최대치: 18% (롤백 전)
- 고객 피해액/수는 확인 불가능

## 타임라인
```
09:02 배포 시작
09:11 API 오류율 2% → 18%
09:14 알람 발생
09:18 롤백 결정
09:24 롤백 완료
09:31 오류율 1.8%로 회복
```

## 직접 원인
1. 캐시 키 생성 함수 교체 (개발 환경에서만 검증)
2. 운영 트래픽과 동일한 키 분포 테스트 미실시
3. 롤백 절차는 문서화되었으나, 실제 실행 시 6분 내 완료됨

## 근본원인/미확정 사항
- 개발 환경 vs 운영 환경의 키 분포 차이 (현재 확인 중)
- 배포 전 검증 범위의 기준 미명시 (진행 중)

## 재발방지 조치
1. 운영 트래픽과 동일한 데이터로 테스트 의무화
